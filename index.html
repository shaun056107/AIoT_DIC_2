    📘 Methodology 方法說明

    Lasso (L1 Ranking)

    Fit Lasso on standardized features at α; rank features by |coefficient|. Ties (zeroed coefficients) are broken by the order in which features enter the regularization path.

    Forward SFS

    Start empty; greedily add the feature that gives the lowest cross-validated RMSE at each step.

    RFE

    Fit OLS on all features, repeatedly remove the feature with the smallest |standardized coefficient|.

    ElasticNet Ranking

    Same as Lasso but with a mixed L1/L2 penalty (L1 ratio ρ); correlated features share weight.

    Exhaustive Search

    Evaluate every combination of k features and keep the best — the optimal subset under the CV criterion.

    Evaluation

    Each selected subset is refit with OLS and scored by out-of-fold RMSE & R² (pooled over folds/repeats). In hold-out mode, selection uses inner CV on the training set only and scores come from the test set.
